Privacy · 6 September 2026

Your records stay in your browser.

Client, quote and change data stays in this browser's IndexedDB. Change Ledger has no account system, analytics, advertising pixels or cloud database.

What is stored

The app stores the clients, projects, base quotes, change cards, frozen approval snapshots and imported receipts you enter. A purchase license and its cached verification result are stored separately in localStorage. Removing site data removes this information, so download backups regularly.

Approval and return links

An approval link contains the selected project summary, client name, change terms, issue time and content hash in the URL fragment after #. Browsers do not send URL fragments to the hosting server. Anyone with the full link can read that frozen record, so share it only with the intended client. Return links contain the decision receipt. An approval link does not include the client's email address.

Exports

JSON backups, CSV files, printed PDFs and receipt files are created on your device. You choose where they go and who receives them. We cannot recover deleted browser data.

License verification

If you add a paid license, the app sends only that token to the Sociobot verification endpoint when you restore it and then at most once each day. Sociobot/Dodo is the merchant of record for checkout. No project or client content is included in verification.

Network and service worker

The app shell is cached locally for offline use. There are no third-party fonts, scripts or runtime CDNs. Ordinary web-server security logs can contain an IP address and requested path, but not URL-fragment approval contents.

Your controls

Use “Import or back up data” to export or restore the workspace. Use browser site-data controls to erase it. Questions can be sent through the contact channel on sociobot.in.

Change Ledger records fixed-price scope changes on this device.
